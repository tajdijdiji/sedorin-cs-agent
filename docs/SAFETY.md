# 安全に使うためのルール

せどりん号CSは「AIが下書き、人が送る」前提で作っています。

| やること | せどりん号 | あなた |
|---|---|---|
| 候補の整理・採点 | ✅ | 確認 |
| 返信文の下書き・値下げ判定 | ✅ | 確認して自分で送信 |
| 購入・決済 | ❌ | ✅ |
| 出品・メッセージ送信 | ❌ | ✅ |

## なぜ自動返信をしないのか
多くのフリマ・EC サイトは、規約でツールによる自動操作や大量アクセスを禁止しています。
違反するとアカウント停止のリスクがあるため、せどりん号CSは **下書きまで** を担当します。

## 法律・規約で気をつけること
- 中古品を仕入れて売るなら **古物商許可**（警察署）が必要です
- 事業として継続的に売るなら、販路ごとのルール（事業者アカウント等）を確認してください
- チケットの不正転売、医薬品・酒類の無許可販売は法律違反です
- 利益が出たら確定申告・住民税の申告を忘れずに

手数料や規約は変わります。`config/` の数字は定期的に公式ページで確認してください。
